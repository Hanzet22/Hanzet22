# Project Status & Release Tracker

Last reviewed: 2026-11-04

This page is a maintainer-authored snapshot. It is not a service-level commitment, release promise, or guarantee that every listed feature is production-ready.

## Status definitions

- **Active development** — changes are being worked on; stability and timelines may vary.
- **MVP development** — core product foundations exist, but the product is not presented as a finished public release.
- **Released** — a version or release is published; ongoing maintenance may still be needed.
- **Temporarily delayed** — progress is blocked or slowed by a dependency, access, or resource constraint.
- **Experimental / archived** — exploratory or historical work; do not assume ongoing support.

## Update policy

- Version numbers are shown only where currently documented in the profile/repository context.
- Release pages are the source of truth for published release assets and tags.
- Status descriptions may lag behind active development; check the repository's latest commits, issues, and release notes.
- A delayed project is not abandoned unless its repository explicitly says so.
- Do not infer that a project is secure, audited, or production-ready solely from its status label.
